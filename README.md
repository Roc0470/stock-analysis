# A股每日短线雷达 · 新手买卖时机与量化分析系统

专为 A 股投资新手设计的**短线爆发与趋势跟踪量化辅助系统**。系统每日盘后或盘中自动抓取市场高流动性核心资产，通过算法模型排除地雷股，计算均线多头、主力放量突破、MACD 动能等核心技术形态，自动生成通俗易懂的高颜值可视化分析报告，并提供**精准买入区间、止盈目标、强制止损红线与仓位控制建议**。

---

## 🚀 快速上手：一键运行

在当前目录 `d:\stock analysis` 下：

### 方式一：Windows 鼠标双击（最简单）
直接双击运行目录下的 **`run_daily.bat`**：
系统将自动完成扫描计算，并在您的默认浏览器中弹出发光质感的《每日短线雷达分析报告》。

### 方式二：命令行运行
```bash
# 激活虚拟环境并运行
.venv\Scripts\Activate.ps1
python main.py
```

| 文件/目录 | 功能描述 |

## 🎯 策略核心理念（大白话版）

针对新手最容易犯的“**追高套牢、抄底阴跌、不舍得止损、重仓单只爆仓**”四大痛点，本系统设定了严格的模型逻辑：

1. **自动排雷与过滤**：
   - 自动剔除 ST、*ST 和退市风险股；
   - 自动过滤成交额低于 3 亿元的冷门死水股（防买得进卖不出）；
   - 自动排除 5 天内暴涨超过 30% 的高位狂热妖股（拒绝当高位接盘侠）；
   - 坚决不碰处于 20 日生命线下方的“空头阴跌股”。

2. **短线爆发评分模型（满分 100 分）**：
   - **均线多头形态 (+25分)**：5日、10日、20日均线多头排列，顺势而为；
   - **放量主力介入 (+25分)**：当日量比大于 1.5 倍，主力真金白银进场；
   - **平台临界突破 (+20分)**：临近或突破 20 日整理高点，上方无密集套牢盘；
   - **MACD 动能强势 (+20分)**：零轴上方金叉或红柱放大，多头加速期；
   - **RSI 健康度 (+10分)**：指标处于 50~72 黄金活跃区间，未现极度超买。

3. **三道绝对量化指令**：
   - 🟢 **建议买入区间**：回踩 5 日线或支撑位挂单低吸，绝不早盘急冲冲追高；
   - 🎯 **第一止盈目标**：通常设定在 +7% ~ +12%，达到后先卖出 50% 仓位锁定本金利润；
   - 🛑 **严格止损红线**：单笔最大亏损容忍度严格锁定在 **-4.5% ~ -4.8%**（或跌破生命线），跌破必须如机器人般坚决离场！

## 🤖 关于“自动买入/卖出（实盘自动交易）”的实现路径

如果您后续希望进一步实现从“报告推送”到“全自动下单”，技术实现路径如下：

1. **A股合规接入方案**：
   - 普通散户由于监管限制无法通过非官方通道直接自动下单。
   - 建议向您开户的券商（如中信、华泰、国泰君安、银河等）申请开通量化交易端：
     - **QMT (迅投)** 或 **Ptrade (恒生)**：券商官方提供的量化交易系统，原生支持 Python 编写下单脚本。
2. **安全过渡机制**：
   - **当前阶段**：以本系统的信号与报告为准，人工在手机券商 App 极速确认并下单（最安全、无程序失控风险）；
   - **进阶阶段**：若已开通 QMT/Ptrade，可将 `strategy_engine.py` 的买卖逻辑接入 QMT 的 `xtquant` 模块，在设定每日最大亏损熔断的前提下进行全自动委托。
